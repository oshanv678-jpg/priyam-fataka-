## 🌟 Highlights

- **Festive Aesthetic**: Deep dark navy & black background with golden glowing borders, animated background fireworks canvas, interactive click-to-launch rockets, and 36 glowing casino marquee light bulbs.
- **14 Wheel Sectors**: Includes actual firework prizes (Shaktimaan Bomb, Anar, Chakri, Rocket, Murga Bomb) and promotional discounts up to 90% and 0 Bill!
- **Mathematical Accuracy**: High-DPI canvas wheel with genuine weighted random probability selection. The top pointer needle decelerates smoothly and matches the won prize 100%.
- **Synthesized Audio Engine**: Built-in sound effects (ratchet peg ticks, launch swoosh, victory fanfare chord, ambient festive sitar/tanpura melody) via Web Audio API with zero external audio assets.
- **Grand Celebration Modal**: Displays winning prize details, generates unique claim voucher codes (`PFS-XXXX-BOMB`), golden confetti celebration, and 1-click code copying.
- **Shop Owner Settings (Admin Panel)**:
  - Enable/disable any prize.
  - Set custom probability weights with live winning chance % recalculation.
  - Spin history logs with unique voucher codes and timestamps.
  - Export logs to CSV and clear history.
  - Customizable store title and spin durations.
  - Stored locally via `localStorage`.
